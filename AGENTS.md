# AI Working Instructions

- The repository is the project memory and source of truth.
- Read current documentation before proposing or making changes.
- Do not invent missing facts; record them in `OPEN_QUESTIONS.md`.
- Distinguish confirmed decisions from assumptions.
- Never add company data, confidential know-how, real compatibility rules, customer data, credentials, internal URLs, or real artifact paths.
- Use only fictional, illustrative examples.
- Update `PROJECT_STATUS.md` and `OPEN_QUESTIONS.md` when decisions change.
- Prefer small, logical changes and do not rebuild multiple documents without need.
- Prefer the simplest architecture that satisfies the requirements.

The human architect makes final decisions. Record significant decisions in ADRs and reflect them consistently in affected documentation.
