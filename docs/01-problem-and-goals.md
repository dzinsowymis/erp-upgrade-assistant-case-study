# Problem and Goals

## Problem

Preparing an ERP upgrade requires a consultant to repeat checks, determine a suitable target version, identify required artifacts, and prepare a result. Manual repetition can take time and lead to inconsistent outcomes or avoidable mistakes.

## AS-IS

`Customer upgrade request -> consultant checks upgrade characteristics -> determines target version -> identifies required files -> prepares response`

## TO-BE

`Customer upgrade request -> automated validation -> target version selection -> artifact mapping -> generated recommendation -> consultant approval`

## Primary Goal

Reduce repetitive manual work required to prepare ERP upgrades.

## Secondary Goals

- Consistency.
- Reduced risk of manual mistakes.
- Faster preparation.
- A traceable decision process.

The consultant remains responsible for reviewing and approving the recommendation.
