# Scope

## In Scope

- Upgrade characteristics validation.
- Deterministic version selection.
- Artifact mapping.
- Result preparation.
- Consultant approval.

## Out of Scope

- Automatic upgrade execution.
- Replacing consultant responsibility.
- Production infrastructure design.
- AI/LLM decision making.
- Detailed company-specific rules.
- Real customer data.

## Boundary

The case study starts when a request and Current Version are available. It ends when the consultant approves, corrects, or rejects the recommendation. Integration and post-approval execution are not defined yet.
