# Security and Constraints

## Repository Safety

- No customer data.
- No credentials or secrets.
- No real internal URLs or infrastructure details.
- No company-specific compatibility rules.
- No real artifact names, paths, or transfer addresses.
- Fictional examples only.

## Solution Constraints

- Process only the least data necessary.
- The consultant remains the final decision point.
- Use deterministic rules, not AI/LLM decision making.
- Do not define production infrastructure at this stage.
- Production would require company-approved infrastructure, access controls, audit controls, data-handling rules, and secrets management.

This is a concept-stage boundary, not a complete enterprise security model.
